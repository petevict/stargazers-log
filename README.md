# stargazers-log
A log of the repositories I've starred.
## Files
- **index.html**: Main page structure
- **script.js**: Loads and renders starred repositories from `events.json`
- **style.css**: Page styling
- **events.json**: List of starred repositories (format: `[{"name": "owner/repo", "starred": "YYYY-MM-DD"}, ...]`)

## How to Update
1. Add or modify entries in `events.json` with the format: `{"name": "owner/repo", "starred": "YYYY-MM-DD"}`
2. Reload the page to see changes
